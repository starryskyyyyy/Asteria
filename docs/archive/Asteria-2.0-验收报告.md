## 本次决定与边界

按用户指定，由同一位 GPT-6 Luna 高思考子代理执行，父代理规划和独立验收；复用执行上下文的风险通过独立检查及真实 CLI 测试弥补。

DSH 采用本机 ACP 接口，因为它支持实时模型目录、原生多轮恢复及会话级 MCP。连接会使用 DSH 的标准 ACP profile；没有修改用户凭据或全局插件配置。

V1 任务保存为只读归档，避免把旧流水线当成新聊天任务重新执行，代价是旧流水线不能作为 V2 会话接续。

当前支持 Codex、DSH。Asteria 子代理深度为一层，每轮最多六个、依次执行、每个最长十分钟。DSH ACP 无法强制只读，因此明确拒绝它的 `readOnly=true` 请求。Markdown 支持常用标题、强调、列表与代码块，不执行 HTML。
